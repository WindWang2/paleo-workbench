# Paleo Workbench UI/UX 深度审查报告 (UI/UX Review)

## 1. UI/UX 现状全景与设计体系

Paleo Workbench 采用 PySide6 构建了以工业地学工作流为主线的现代桌面界面体系，融合了 GIS（QGIS / ArcGIS Pro）、地质勘探（Petrel）与三维可视化（ParaView）的核心交互模式。

```
+-----------------------------------------------------------------------------------+
|  MenuBar: 文件(F)  编辑(E)  视图(V)  图层(L)  算法(A)  制图(M)  质检(Q)  帮助(H)       |
+-----------------------------------------------------------------------------------+
| [IconRail] | [工序/资产导航树] | [主工作区 / 多模式画布 / 3D视口] | [属性检查/操作面板] |
| 首页 (Home) | - 项目资产目录    | - 单井/连井绘图区                | - 属性表/直方图     |
| 数据 (Data) | - 井位散点分布    | - 地震正交剖面 (Inline/Xline/Time)| - 样式/符号配置     |
| 格架 (Seq)  | - 地层层序对比    | - 单因素网格/等值线图             | - 证据链与推理卡片  |

```

## 2. 桌面端 UI 审查与问题诊断

### 2.1 设计语言与 Design Tokens (`paleo_workbench/ui/tokens.py`)
- **优点**:
  - 建立了系统化的设计令牌体系（Design Tokens），定义了统一的深色调基色（`#181c22` 背景、`#22272e` 面板、`#316dca` 强调色、`#58a6ff` 悬停色）。
  - 字体层级规范化（Header 16px Bold, Body 13px Regular, Caption 11px）。
- **待改进项 (P3)**:
  - **浅色主题支持不足**: 目前样式表主要针对深色（Dark Theme）优化，缺乏动态一键切换高对比度浅色主题（Light Theme / Paper Print Theme）的能力，无法满足学术发表和户外打印需求。
  - **高分屏与缩放适配**: 部分固定像素尺寸（Fixed Width/Height）在 4K/2K 高 DPI 屏幕下出现文字截断或控件边缘重叠。

### 2.2 交互布局与信息密度 (Benchmark 对标)

| 功能维度 | Paleo Workbench 当前现状 | 行业标杆 (QGIS / Petrel / ArcGIS Pro) | 差距与优化空间 |
|---|---|---|---|
| **面板系统 (Docks)** | 固定网格分割器 (QSplitter) | 多级自由浮动、停靠、折叠、标签化 DockPanel | 需支持自由停靠与工作区预设 (Workspace Presets) |
| **图层树 (Layer Tree)** | 自定义树控件，支持显隐控制 | QgsLayerTreeView，支持组/图层拖拽排序、混合模式、符号预览 | 需增加图层混合模式（Blend Mode）与符号缩略图实时渲染 |
| **属性检查 (Inspector)** | 针对特定资产的专用属性面板 | 通用 Dock 属性表，支持字段编辑、条件格式化、直方图过滤 | 需建立统一的反射式通用属性面板（Universal Inspector） |
| **样式编辑器 (Style)** | 基础单色/色阶弹窗 | 丰富的 Rule-based 样式树、SVG 符号选择器、连续渐变生成器 | 需对齐 QGIS 符号化对话框体系 |
| **制图输出 (Composer)** | 简易多格式导出对话框 | 强大的 Print Layout 编图器（图名/图例/比例尺/指北针/坐标网格）| 需构建完整的声明式 Map Composer 页面 |

## 3. Web UI / 单独原型审查 (`古地理图编制系统 (standalone).html`)

- **审查发现**:
  - 仓库内包含完整的基于 HTML5 Canvas / SVG 的单文件独立原型 `古地理图编制系统 (standalone).html`。
  - 原型展示了优秀的 Web 端图层管理、多边形绘制、断层遮挡以及单因素渲染流程，交互轻快直观。
- **融合建议**:
  - 将 Web 原型中优秀的交互动效（如断层影响廊道拖拽手柄、井位权重实时滑块、流线型动画）移植至 Qt 桌面端，提升桌面软件的现代化质感。

---

## 4. 关键 UI/UX 缺陷与优化清单

1. **工作区布局预设缺失 (P3)**:
   - 用户在“数据清洗”、“测井解释”、“单因素插值”与“地图整饰”不同阶段需要完全不同的面板布局，目前缺乏“测井工作区”、“制图工作区”、“三维建模工作区”一键切换功能。
2. **操作步骤撤销/重做可视化弱 (P3)**:
   - 拓扑编辑虽然底层实现了 Undo/Redo 栈，但缺乏可视化的“历史记录面板（History Dock）”，用户无法直观查看操作快照。
3. **参数配置复杂度与引导性 (P3)**:
   - 部分算法参数（如 IDW 幂次、搜索半径、相干时间窗）缺乏交互式即时预览与智能推荐默认值（AI Parameter Advisor）。

---

## 5. UI/UX 重构与升级方案

1. **构建 QGIS / ArcGIS Pro 风格的 Dockable Workspace**:
   - 引入 `QDockWidget` 管理图层树（Layer Tree Dock）、属性面板（Property Dock）、工作流向导（Workflow Dock）、工具箱（Toolbox Dock）。
2. **建立 Dark / Light / Scientific 双主题引擎**:
   - 抽象 `ThemeManager`，通过 QSS 变量动态注入深色、浅色及地质专业高对比度主题。
3. **开发可视化 Map Composer (地图排版器)**:
   - 提供拖拽式图件整饰画布，支持比例尺、图例、指北针、图框与地质年表组件自由排版与高精度打印。
