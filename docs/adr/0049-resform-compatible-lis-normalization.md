# ResForm 兼容的 LIS 规范化与导入边界

LIS79 导入以 `resform-compatible-v1` 归一化 Profile 提供可审计的曲线别名、单位、缺失值与文本解码规则；Profile 指纹与源内容及逻辑数据集身份共同决定导入实体身份。导入必须保留全部可用数据段、独立采样轴、源顺序和重复索引，不得隐式拼接、重采样或解释校正；物理边界无法确认时拒绝文件，边界可确定的局部不支持或损坏则隔离数据集并产生诊断。这样用 ResForm 的用户可见工作流作为兼容目标，同时以公开 LIS79 规范而非私有格式作为二进制事实来源。

## Consequences

- 变更默认 Profile 规则必须以新版本发布，不能改变既有 `resform-compatible-v1` 的语义。
- 多逻辑文件需显式选井（仅一候选可直接导入）；曲线/轴/数据段不因名称或相同坐标被自动合并。
- 仅在前一 DFS 后已有数据时，后续 DFS 才开始新数据段；相邻且无数据间隔的完全重复 DFS 是冗余元数据，折叠并诊断，非相同 DFS 则由后一个取代前一个且不生成空数据集。
- LIS84、模糊物理封装、无效 Profile 和资源上限越界均必须明确拒绝，不能猜测或静默截断。
- 正常导入只以来源、再分发许可和去敏状态均可证明的真实 LIS79 文件作为生产样例；程序化样例限于损坏与资源边界测试。
