# feat(app): wire mapping_kernel into MainWindow geological-factor map action

## 用户流程（本切片验收）

打开工程 → 选/导入井点（XY+因子）→ 跑 IDW（或克里金）→ 画布出现
**等值线**与**相带多边形**图层（非空）。不要求 composer 出图。

C++ 平台的「地质(&G) → 地质因子图…」governed 菜单动作（`factor_workbench`，
policy 门禁：无工程 → 禁用并显示「未打开工程」）现在完成了这条链路：

```
井点记录（画布点图层要素 或 内置 8 井 fixture）
  → pwb::mapping::extract_factors        （冻结核，audit #1150 坐标族）
  → pwb::mapping::interpolate_factor     （冻结核：IDW / Ordinary Kriging）
  → pwb::mapping::marching_squares_contours（冻结核，16 例+鞍点+缝合）
  → pwb::mapping::classify_grid + polygonize_class（冻结核，洞归属）
  → GeoJSON Feature 数组（与 Python geological_pipeline 图层构造器同契约）
  → QgsVectorLayer（memory provider）×2：{factor} 等值线 / {factor} 相带
```

数值核零改动（M6/M7 已冻结核只读复用）；新编排层
`pwb::application::run_map_pipeline` Qt-free，Qgs* 只在 main_window 接线。

## Oracle 对账（真实 Python，非手写期望）

`tools/oracle/generate_map_pipeline_fixtures.py` import **真实**
`paleo_workbench` 模块，把全链（extract → interpolate → contour 层 →
相带层）的输出冻结为 `tests/cpp/platform/fixtures/map_pipeline_oracle.json`，
并内置断言：shapely repair 在格元描边环上是恒等（否则 C++ 冻结核无法
复现，生成即失败）。

**11 个冻结案例**，每个逐格元/逐特征对账：

| 案例 | 覆盖 |
|---|---|
| eight_well_idw | 8 井孔隙度 IDW + 显式 levels/thresholds（test_geological_mapping_pipeline 同 fixture） |
| eight_well_kriging_defaults | 克里金分支 + 全默认（nice 阶梯/⅓·⅔ 阈值/默认相带名与色板） |
| eight_well_idw_defaults | 窗口对话框发出的精确请求（IDW g30 全默认） |
| qc_filtered_idw | qc_flag=bad 井被剔除（7 有效点插值、8 井 extent） |
| undeclared_crs_idw | 未声明 CRS → planar 诚实注记 + unknown-unit² |
| projected_crs_idw | 投影 CRS → "{crs}-unit²" / 无 area_approx_m2 / planar 已验证注记 |
| insufficient_points | 失败分支：validate() 文案逐字对账（Python ValueError） |
| all_nodata_min_neighbors | 全 nodata 网格 → 0 等值线/0 相带 + NaN 统计 |
| search_radius_partial_nan | 半径裁剪 → 部分 nodata，等值线/相带跳过 NaN 格元 |
| constant_field_defaults | 常值场 → 0 等值线 + 1 相带 area_percent=100 |
| zero_coordinate_kept | audit #1150：(0,0) 合法坐标 + 混合键族跳过不交叉配对 |

对账范围：网格逐格元（NaN 模式 + 值 ≤1e-6）、统计量（1e-9）、
distance_policy 注记、等值线/相带全部特征（几何坐标 ≤1e-9、
label_text/level/is_index_contour/is_closed/length、facies_id/name/color/
area/area_unit/area_percent/mean_value/area_approx_m2）。

## 范围与边界

- 只追加：kernel 零改动；既有 43 项测试（含 toolpolicy golden 全矩阵）
  无降级。
- CMake 仅 `BEGIN CONV-01`/`END CONV-01` 块（root fail-closed option
  `PWB_BUILD_CONV_01`）。
- 明确未移植（后续切片）：catalog 版本发布/FactorMapTask/staleness 锚点/
  composer/边界裁剪（Python shapely repair 亦不移植，与冻结核一致）。

  geoviz WLS 引擎是不同估算器、未移植（M6 既定边界）。对话框条目已
  如实标注「克里金插值（numpy 回退估算）」。
- 相带/等值线图层按 workspace 角色注册（`factor_contour`/
  `factor_classification`，RAW 保护，不授编辑）。
