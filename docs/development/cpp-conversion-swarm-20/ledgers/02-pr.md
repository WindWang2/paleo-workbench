# PR：feat(mapping_document): Qt-free MapDocument and composition JSON kernel with Python oracle

## 用户流程（本切片验收）
一份 Python 写出的 map document JSON 能被 C++ 读回且语义相等；C++ 写出的能被 Python 读回（composition 走真实 `MapCompositionDocument.from_dict` 对账）。不做 QgsLayout、不做渲染。

## 交付物
- 新库 `libs/mapping_document`（Qt-free，仅依赖 `Pwb::Domain` 的 ordered_json + 语义比较器）：
  - `MapDocument` / `MapLayer`：layers.py 的 to_dict 键序契约、读侧默认填充、vector/annotation family 路由（D-05）、未知键 extras 保真（§7.4）、add/remove/reorder/recompute_extent/input_version_ids 全语义移植。
  - `Composition` / `ComposerElement`：models.py 的 from_dict/to_dict 双向契约——`_raw_element_type` 载体与 pop quirk、`or`-falsy vs `get(default)` 两种强制转换、稳定 z 排序、set_paper（含逐字符错误文案）、`composition_page_pixels`（Python 银行家舍入经 `std::nearbyint` + IEEE754 求值顺序钉死）。
- Oracle：`tools/oracle/generate_map_document_fixtures.py` 真实 import 产品码（含 pipeline/模板工厂/registry 默认），冻结 **48 案例**（22 文档 + 16 组合 + 10 像素）到 `libs/mapping_document/mapping_document_tests/fixtures/map_document_oracle.json`；生成器自断言幂等且字节确定（重生成逐字节一致）。
- 测试：`mapping_document.roundtrip`（151 检查：每案例 round-trip 语义相等 + probes + 冻结 ops + 返回值对账 + 像素/纸张表）。
- 根 CMakeLists 仅追加 `BEGIN CONV-02` 块（`PWB_BUILD_CONV_02`，默认 OFF）。
- 台账：`docs/development/cpp-conversion-swarm-20/ledgers/02-findings.md`（§5 全文件逐符号契约）、`02-decisions.md`（D-01..D-24）、`.goal-loop-ledger.md`（轮次）。
