# feat(mapping_kernel): GeoJSON contour and facies layer products from mapping_kernel

CONV-03（cpp-conversion-swarm-20 任务 03）。把 Python 产品
`generate_contour_layer` / `generate_facies_polygon_layer` 的**要素打包**
（geometry + properties，无样式 UI）迁入 Qt-free 的 `libs/mapping_kernel`
新文件 `layer_products.*`，对 Python 属性键序与 `round(area, 4)` 半偶舍入
语义逐位对账。冻结 oracle 与既有 mapping_kernel 套件本地全绿（不依赖线上
CI；未等待任何 GitHub Checks，未改动 `.github/`）。

## 用户流程验收（本切片）

给定 FactorGrid + 阈值/interval/levels，C++ 产出的 Feature 列表与 Python
图层的 features 在 geometry 与关键 properties 上**逐位一致**（在 shapely
repair=identity 前提下，与已合入的 polygonization 切片同口径）：

- 等值线特征：`level / label_text（%g 格式化）/ is_index_contour（interval
  走 Python % 语义 + isclose abs 1e-5；否则 idx%5）/ length（CPython
  math.hypot 算法）/ is_closed（isclose rel+abs 双容差）/ factor / unit`。
- 相带特征：`facies_id / facies_name / facies / color / area（round 4 半偶）/
  area_unit（deg²/{crs}-unit²/unknown-unit²）/ area_percent / mean_value
  （numpy float32 pair-wise 均值核）/ [地理 CRS: area_approx_m2]`。
- QC 元数据全量对账：`contour_qc`、`polygon_qc`（thresholds、
  thresholds_source、nodata_cells、total_cells、area_warnings 双文案、
  holes_promoted_to_exterior、small_polygon_threshold 逐字回显）。
- 早退分支：全 NaN/全 Inf/单胞网格的空产物与 Python 逐字段一致。
- 不迁移（有意，见 `docs/development/cpp-conversion-swarm-20/ledgers/
  03-decisions.md` D1/D2）：clip-to-ring（Python 硬依赖 shapely/GEOS，坐标
  无法逐位复刻）、样式/categories/图层 id。

## Oracle

- 生成器 `tools/oracle/generate_layer_product_fixtures.py` **import 真实
  Python 实现**（repair 打 identity），零手写期望值；冻结
  `layer_products_oracle.json`：**28 个 contour + 30 个 facies 案例
  （282 个 feature）+ 10 组 numpy float32 均值核（mean_units）**。
- 覆盖：nice/quantile/interval（含 interval≤0、-0.0 起点、负 flevel 取模、
  极端量级 %g、simplify/smooth、显式空 levels）、min_area 四态、CRS 三态、
  阈值乱序重复、名称截断/显式颜色、洞升级 QC 管道、12 类空产物早退。
- C++ 侧 `python_hypot` 另做 **30 万对**独立模糊对拍（随机/极端量级/次正规/
  nan+inf 组合/等长段）：0 失败。
