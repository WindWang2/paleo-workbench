# CONV-05 — constrained IDW kernel ported from Haiyou adapter with oracle

## 用户流程（本切片验收）

带断层折线约束的井点插值：**C++ 网格与 Python `run_constrained_idw` 在冻结小场上逐格对账**。
数值核 = vendored 引擎 `generate_constrained_idw` 的表面（grid）路径——约束 IDW 插值
（断层硬视线阻断 + 分区 + 曲线走廊各向异性 + along-track 拉伸 + 补洞/平滑/域边过渡 +
井点残差锚定 + 断层走廊 nodata），Qt-free、Python-free、scipy 语义内联（精确 EDT）。

## 移植范围与诚实 skip（详见头注释与 05-decisions.md）

- **进 C++**：表面网格全链 + 54 个表面 diagnostics + 三个引擎级错误分支（异常文案逐字一致）。
- **不进 C++**：等值线提取/后处理链（在返回网格定型之后才运行；Python 自证
  extract_contours=True/False 网格 bit 相等，fixture 中两种运行独立冻结）、宿主胶水
  （shapely/GEOS 凸包缓冲、pyproj CRS 启发式、CV R²/anchored fidelity 指标）。
  C++ 消费引擎级契约（wells/boundaries/barriers/directions/config）。

## Oracle（全部来自真实 Python 运行）

- 生成器 `tools/oracle/generate_constrained_idw_fixtures.py` import 真实
  `paleo_workbench.workflow.constrained_idw_adapter` + vendored 引擎，用 spy 捕获
  adapter 传给引擎的**精确输入**（dataclass asdict；只捕获表面 pass，排除 CV 4 折重入），
  期望值全部来自真实 `run_constrained_idw` / 引擎直调——零手写期望。
- **12 个冻结案例 / 16,025 网格格元**：无约束平面 9 井（批核路径）、贯穿断层厚度场
  （LOS+分区+走廊 nodata）、死端断层 6 分辨率（#382 语义）、重复坐标井 first-wins
  （#399）、纯方向线（批核各向异性 + along-track）、方向+断层（逐格曲线走廊）、
  双方向交叉（dual-angle 汇合）、度 CRS 显式缓冲（#400）、extract_contours=False 引擎直调、
  3 个引擎错误分支（<3 井 / 无边界 / 边界无顶点，异常文案精确匹配）。
- 对账口径（D5）：NaN 图案逐格相等；finite 差 ≤ max(1e-8, 1e-9·|want|)（测试中真实断言
  worst ratio ≤ 1）；54 项诊断精确对账；min/max/mean 以完整 numpy pairwise 树重算对账；
  轴 ≤1e-12。实测各阶段差 ≤ 1.8e-15。
