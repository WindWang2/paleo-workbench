# CONV-06 — WorkflowSpec DAG 纯模型 + 校验器（Python oracle 对账）

## 用户流程（本切片验收）

一份 Python 导出的 DAG spec JSON，C++ 加载后校验结论（通过/失败原因）与 Python 一致：

- Python 侧 `WorkflowSpec(...).to_dict()` / recipe 落盘的 spec JSON，C++
  `WorkflowSpec::from_dict` 加载，`validate_workflow_spec` 校验；
- **失败原因逐字对账**：`problems` 列表按序全等（含 f-string 的 `!r` repr、
  sorted 列表渲染、正则 pattern 字面量），不是子串匹配；
- 合法 spec：`from_dict → to_dict` 与 Python 重序列化**字节级一致**（键序钉死），
  `spec_hash`（canonical sha256）与 Python 全等；
- JSON round-trip 同样覆盖 NodeCondition / NodeRun / WorkflowRun
  （含 store schema drift 容忍与全部 7+5 枚举值）。

## 范围

忠实移植 `paleo_workbench/workflow/dag/model.py` + `validation.py` 的全部纯数据
结构与校验（含依赖的 `providers.execution.validate_parameters` JSON-schema 子集）。
**不含执行器**（engine/store 是 07 切片）、不含 recipe/plan_view/dependency_graph。
`ActionRegistry` 折叠为最小 `ActionCatalog`（`action_id → risk` 表）——静态门对
registry 的真实依赖面只有查找成败与 risk 值（06-decisions.md D2）。

新库 `libs/workflow_spec`（Qt-free，仅依赖 `Pwb::Domain` 的 ordered_json + sha256）；
根 CMake 只追加 `BEGIN CONV-06`/`END CONV-06` 块（`PWB_BUILD_CONV_06`，默认 OFF）。

## Oracle（全部由真实 Python 计算，无手写期望值）

生成器 `tools/oracle/generate_workflow_spec_fixtures.py` import 真实
`paleo_workbench.workflow.dag.{model,validation}`、`paleo_workbench.harness.registry`、
`paleo_workbench.providers.execution`，冻结出：

| 区段 | 案例数 | 说明 |
|---|---|---|
| valid_specs | 27 | 校验通过 + 重序列化字节对账 + spec_hash |
| invalid_specs | 46 | 校验失败分支 + 完整 problems 列表逐字对账 |
| condition_trees | 17 | validate_condition_tree 全 kind/嵌套/空串真值 |
| slot_bindings | 24 | materialize_defaults + slot schema（类型/enum/bounds/items/union/污染 schema） |
| resolve | 18 | $slot/$ref/$context 解析与 BindingError 文案 |
| canonical_hash | 9 | 排序键/紧凑 dump/中英文/int-vs-float |
| run_roundtrip | 4 | NodeRun/WorkflowRun 全字段 + drift + 全枚举状态 |
| from_dict_error | 5 | Python 抛（KeyError/ValueError）↔ C++ 抛 |

DESTRUCTIVE 分支经 duck-registry 驱动真实 `validate_workflow_spec` 冻结（生产
registry 注册期拒绝 destructive，Python 该分支 pragma-no-cover）。
fixture 两次再生成字节级一致（确定性）。

1. **正确性**：自查（schema_version presence-wins 偏差）+ 对抗性审核
   （subagent）：修 13 项（P1：条件树空字符串真值；其余：to_dict 键序、正则
   `$` 尾换行、falsy 容器 or-语义、bool() 真值、state 非串抛、时间戳 int 保真、

   node_runs dict 语义等）；4 项记为已声明偏差（06-decisions.md D11）。
