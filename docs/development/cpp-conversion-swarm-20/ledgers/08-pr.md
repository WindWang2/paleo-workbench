## CONV-08 — 因子插值任务宿主（plan / fingerprint / 评价叶子）

### 用户流程

本切片回答两个科学问题，全部以「与 Python 逐字节/逐语义一致」为验收：

1. **同一组井点 + 参数，指纹是否一致？** `build_factor_fingerprints` 对
   normalized 样本集产出 geometry / values / algorithm / constraints / result
   五个 SHA-256 组件指纹，编码为 Python `json.dumps(sort_keys=True,
   ensure_ascii=False, separators=(",",":"))` 的字节级复刻——C++ 与 Python
   历史哈希互认，增量重算（CLEAN/DIRTY 分类）可整体搬进 C++ 宿主而不触发
   全量误重算。
2. **评价指标在冻结网格上是否一致？** bilinear 采样（含 numpy 负索引语义的
   退化网格）、signed R²、RMSE/MAE/bias（含诚实跳过计数）、确定性空间 K 折、
   LOWO 分折、surface 残差、推荐裁决与 fail-closed 门禁，全部对冻结 oracle
   对账。

不接 UI、不跑 geoviz 引擎；`interpolation_plan` 只落数据结构切片
（xy_signature / PlanKey / grid 轴 / build_idw_plan / extract_values_aligned
/ 会话 LRU plan cache / JSON round-trip），值相关的 IDW apply 引擎与
LOS 掩码留在 Python 侧。

### 范围

- 新库 `libs/factor_host`（`pwb::factor_host`，Qt-free / Python-free /
  numpy-free，仅依赖 `Pwb::Domain` 的 nlohmann JSON 与 Sha256）：
  - `canonical_json` — Python canonical JSON 编码器（`repr(float)` 最短往返
    格式、sort_keys、compact、非 ASCII 原样）。
  - `fingerprint` — extract_sample_records / resolve_backend / backend_uses_*
    / build_factor_fingerprints / FactorFingerprints / FactorDirtyState /
    stored_fingerprints_from_task / task_has_numerical_output /
    classify_factor_recompute。
  - `evaluation` — bilinear_sample_grid / signed_r_squared / EvaluationMetrics
    / spatial_fold_assignment / leave_one_well_out_folds /
    cross_validate_surface / surface_residuals / residual_features /
    validate_recommendation_context（CRS 校验注入化，fail-closed 默认）/
    adjudicate_recommendation。
  - `plan` — xy_signature / fault_signature / PlanKey / grid_axes_from_samples
    （numpy linspace 逐位复刻）/ InterpolationPlan（+ JSON round-trip，宿主侧
    新增契约）/ build_idw_plan / extract_values_aligned / PlanCache。
  - `interop` — resolve_engine_method / variogram_settings_from_params /
    interp_params_from_task。
- oracle：`tools/oracle/generate_factor_host_fixtures.py` 用 importlib 绕过
  PySide6 加载**真实** `geoviz_plots` 叶子后 import 真实 workflow 模块，冻结
  **179 个案例 / 3370 项断言**（fingerprint 28 组件案例、classify 17 态矩阵、
  plan 签名/键/轴/文案、evaluation 全指标、interop 全表）。生成器重跑
  sha256 逐位一致（可复现）。
- CMake：根 CMakeLists 仅追加 `BEGIN CONV-08` / `END CONV-08` 两个小块
  （option `PWB_BUILD_CONV_08`，默认 OFF）。
- 文档：`docs/development/cpp-conversion-swarm-20/ledgers/08-findings.md`、
  `08-decisions.md`（D-1..D-15，含两轮审核的全部修正记录与剩余分歧清单）。
