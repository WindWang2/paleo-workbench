## Oracle（53 案例全冻结，跑真实 Python）

- 解释器：项目 venv python（3.12.13 / numpy 2.5.2）；worktree 内真实模块。
- normalized ×10：NaN/±inf 插补、全 NaN、空、单点、常数、符号溢出、
  均值溢出（-inf 输出）、1e6 大偏移。
- downsample ×9：恒等（bin≤1）、空、min/max 序、持平 bin、残尾 bin、
  并列首下标、NaN 首 NaN 优先（numpy argmin/argmax 语义）。
- match ×27：移位/恒等/常数/NaN 注入（E3）/不等长/窗口拒绝与边界
  （#897）/窗 0/薄层 4000 点（#1054，stride 8）/尖峰移位/20000 点
  （E8，stride 40）/空曲线/全 NaN/float32 上转/0.5 网格量化平局/负域/
  左缘回溯/随机游走/±1e308 溢出（inf 代价）。
- transfer ×7：移位、空路径直通、并列保最先、非单调就近、越界、zip 短截断。

## 位级对账方法（为何路径能全等）

Python 回溯器用 `min_val == cost[i-1,j-1]` 精确比较破平局（斜>上>左）。
C++ 复刻 numpy 的 pairwise summation（n<8 顺序；n≤128 八累加器树形合并+
余项；>128 二分对齐 8 倍数），使归一化曲线与 np.mean/np.std **位级一致**
（本机 numpy 2.5.2 上 1500+ 随机数组验证 0 失配）→ DP 矩阵位级一致 →
平局判定一致 → 路径索引全等、代价 `==` 相等。
