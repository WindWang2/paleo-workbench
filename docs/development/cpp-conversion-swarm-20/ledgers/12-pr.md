# CONV-12 — formation_volume / geomodel 纯几何核（C++ 移植 + 冻结 Python oracle）

## 用户流程

给定层位网格或闭合多边形，C++ 体积/厚度与 Python 一致：

- `FormationVolumeIntegrator.compute_closed_volume`（Gauss 散度定理闭合体）→
  `pwb::geomodel::closed_mesh_volume`；
- 层位网格 → 三角化（NaN 洞不造三角形）、闭合地层体 shell（交叉柱丢弃并
  计数、TVDSS z 向约定、形心朝外定向、边流形闭合检查）、柱状六面体计算
  网格 → `pwb::geomodel::{triangulate_heightfield, build_volume_shell,
  build_columnar_hex_mesh}`；
- 顶/底面之间的竖向厚度（双线性插值、NaN 洞 fail-closed）→
  `pwb::geomodel::thickness_at`（附 point/distance/polyline/vertical
  difference/plane orientation 全套 domain 测量与 `format_result` 文案）；
- 剖面交线（平面/网格/层位/井穿越、GL clip 方程）→ `pwb::geomodel::section`；
- 交互面：高斯刷雕刻 + laplacian 平滑 + undo/redo（`horizon_sculpting`）、
  锚定断层位移 + 符号 heave + 衰减（`fault_displacement`）、QC 数值子核
  （退化三角形比例/边流形/连通分量，scipy 语义）。

**明确不迁**：3D 渲染/OpenGL（scene_adapter）、demo 合成数据、geoviz 引擎
pass-through（analysis）、exporters 文件格式层、advisor 业务规则、
real_geological_scene（project/catalog 域）——见
`12-findings.md`（逐文件 5–20 行/公开符号）与 `12-decisions.md` D2。

## Oracle

- 生成器 `tools/oracle/generate_geomodel_volume_fixtures.py` **import 真实
  Python 模块**（`paleo_workbench.viz.*`），期望值零手写；
- **110 个冻结案例**（`geomodel_volume_oracle.json`），12+1 族：
  volume 9 / sculpt 11 / fault 12 / triangulate 4 / curtain 5 / shell 12 /
  hex 11 / pip 2 / dedupe 4 / measure 19 / section 13 / meshqc 6 /
  horizon_err 2；
- 覆盖每个移植公开函数 + 每个失败分支（报错文案逐字，含中文/°/numpy
  reshape 格式）；NaN 以 JSON null 表示；容差全部由 fixture 字段携带
  （测试零魔法数）；
- float32 链路（+−×÷）目标逐位一致；超越函数/libm 档 1e-4；SVD vs Jacobi
  档 1e-6；float64 求和档 1e-9 相对。
