# feat(prediction): tiled inference geometry and CPU stub matching Python tiled_onnx

## 用户流程（本切片验收）

一张小 2D 网格（地震体 2D/3D 均有覆盖）按**同一 tile / halo 策略**切块拼回，
C++ 与 Python **逐格一致**：

- 切块：`tile_starts(n, tile, overlap)` —— `range(0, n-overlap, tile-overlap)`，
  n ≤ tile 时单块；`tile <= overlap` 诚实报错。
- 重叠：`receptive_field` halo（默认 8，0/3/4 均有冻结案例；奇数 overlap 的
  `overlap//2` 不对称裁剪已钉死）。
- 拼回：center-crop 融合，`authoritative_range` 给出 [0,n) 的**精确划分**
  （每体素恰好一次权威预测，无缝无叠），边片高地址端零填充。
- CPU stub：本机无 libonnxruntime → 推理会话是接缝
  （`pwb::prediction::InferenceSession`），oracle 生成器在 Python 侧同一接缝
  （`_make_session`）注入可复现 stub 算子（per-voxel sign / 固定可分离二项式
  卷积 / 3 类平局 / C=1 sigmoid），驱动**真实的**
  `paleo_workbench.prediction.tiled_onnx.run_tiled_inference`，冻结 JSON；
  C++ stub 算子逐位复刻（`-ffp-contract=off`，固定求值顺序）。
- 契约同样入移植范围：softmax 中间量预算守卫（#1187，显式报错不静默钳制）、
  ONNX 模型文件门（#1176，后缀/大小帽/sha256 绑定）、per-tile `.done` 恢复
  标记（含 fsync 与垃圾 marker 容忍）、OOM 批量半退避（`_looks_like_oom`
  文本分类 + 4→2→1 退避）、取消协议（#1167，cancelled 结果不带 model
  binding）、诚实 `mode="cpu"`。

不依赖 libonnxruntime、不依赖 QGIS/Qt；`find_package(onnxruntime CONFIG QUIET)`
可选拼装已声明（本切片无 ORT 专属翻译单元，见 13-decisions.md D8）。

## oracle 案例数

`tools/oracle/generate_tiled_onnx_fixtures.py`（跑真实 Python，禁手写期望值）
冻结 **47 案例**（libs/prediction/prediction_tests/fixtures/tiled_stub_oracle.json）：

| 组 | 数量 | 覆盖 |
|---|---|---|
| tile_starts | 8 | 含 n≤tile、尾块截断、tile≤overlap 报错文案 |
| authoritative | 7 | 首/内/末划分；生成器侧断言精确划分性质 |
| softmax 预算 | 6 | classes/batch 超限文案 + ==边界两侧 |
| model 文件门 | 5 | ok(binding+sha256)/后缀/目录/空文件/大小帽 |
| 完整 run | 14 | sign/conv2/conv3/sigmoid1/NaN/三处精确平局(1,2,2.5,0.5)/OOM 半退避/取消×2/恢复×3；每案冻 stats+全量 classmap+全量 probmap(fp16)+done 标记 |
| run 级错误 | 7 | 模型缺失/非模型/零 tile/零 classes/batch 0（ValueError）/ndim 4/ndim 3 文案逐字 |

对账断言（`prediction.tiled_stub`，**268 checks**）：classmap uint8 **逐体素
精确相等**；probmap float16 逐体素 ≤ 1 fp16 ULP（exp() 实现差 ~1 fp32 ULP 被
fp16 舍入吸收的容差，13-decisions D6）；错误文案 `<WORK>` 占位符代入后逐字节
相等；tiles.done 标记集合与统计（tiles_total/done、batch、cancelled、
binding_present）逐项相等。
