# conv-14 — interchange path-safety / package manifest / preflight 纯核（C++）

## 用户流程

给定一组工件路径，C++ preflight **拒绝路径穿越**（`..`、绝对路径注入、NFD 非
NFC、casefold 碰撞、Windows 保留名、尾点/尾空格、超长、C1/分隔符 repr 语义）
并写出**与 Python 逐字节同构**的 `manifest.json`（ordered 键序、
`ensure_ascii=False, indent=1`、`entry_count` 派生）；preflight 决策树
（missing/directory → 内容嗅探结果 → SNIFF_FORMAT_ALIASES → 扩展名/内容
置信度分支 → format-unknown → inspection → capability → recommendation →
estimated 字节口径）与 Python `ImportPreflightService.inspect` 逐分支同构，
失败计划的错误文案（`；` 连接）逐字一致。不含上传、不调用外部对象存储。

## 移植范围（诚实清单）

**移植**：`path_safety.safe_relative_path / check_collision /
ensure_within_root / sanitize_filename / is_reserved_or_unsafe`（含 NFC 归一、
full casefold——表由系统 python3 unicodedata（Unicode 16.0.0）生成，Hangul
公式化）；`package.manifest` 全部（to_dict/from_dict/dumps/validate_paths/
entry_paths/write/read，含 Python `str()/int()` 强转语义与错误消息）；
preflight 决策树 + `PreflightIssue/PreflightReport/ImportPlan` +
`InterchangeRegistry` 投影（insertion-order 扩展名查找、duplicate/blank 错误）。
**不移植（后续切片）**：zip 容器（safe_members/extract_archive）、
os_replace_atomic 的 Windows 重试策略、内容嗅探本体、各 adapter 重解析引擎
（geoviz/rasterio/segyio/GDAL/openpyxl/lasio）、builder/verifier/executor/
batch/delivery/dependency_audit（catalog 依赖编排，M9）。

## 三轮审核

1. **正确性（差分）**：fuzz 语料差分；发现并修复 Hangul starter+starter 组合
   缺失、symlink 目标构造错误、entry_paths 双临时 set 迭代悬挂、JSON
   int/unsigned 类型比较差。
2. **对抗性 spec 审核**（独立 subagent）：3 P1（NFC 组合阻断规则 fail-open、
   starter+starter 表组合死代码、Unicode 空白集不全）+ 4 P2 全部修复，
   oracle 由 146 → 657 案例。
3. **Karpathy 质量**（独立 subagent）：死代码/调试残留清除、_WIN32 半支持
   脚手架移除（POSIX-only 对齐 mapping_kernel）、python_repr C1 区间补齐、
   决策账本与实际行为同步。
