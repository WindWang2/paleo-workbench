# CONV-17 — geometry units and CRS contract leaves beside crs_policy

## 用户流程(本切片验收)

地理 CRS 的环面积带单位标签与 Python 一致;未声明 CRS 不得被猜成 4326。

- `ring_area_with_unit` / `polyline_length_with_unit`:地理 CRS 下输出
  均值纬度局部尺度 ≈m²/≈m 近似 + 显式 warning(平方度不再冒充 m²);
  投影 CRS 保留 CRS 轴量纲;未声明 → `unknown-unit²` + warning。
- `resolve_crs` / `panel_publish_crs`:未声明永远带降级判词,绝不静默
  4326;`infer_crs_from_extent` 只建议、不代用户声明;声明域 vs 数据域
  的可证明失配(`coordinate_domain_mismatch`)进核。
- 与已有 `crs_policy` 分工明确:谓词复用 `pwb::mapping::crs_is_geographic`
  (单一轴真值),本切片只加「声明/单位/域」层;**不复制 pyproj**——
  未知 CRS / 投影 area_of_use 域 / 米轴判定,一律诚实 unknown(nullopt),
  与无 pyproj 的 Python 同径。
