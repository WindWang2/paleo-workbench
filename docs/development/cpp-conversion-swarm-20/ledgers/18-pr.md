# feat(mapping_kernel): FactorGridResult JSON envelope codec with Python oracle

C++ 转换任务 18(全面转换阶梯 M7 工作流引擎核叶子)。基线 `origin/main` @ `35987e13`。

## 用户流程

Python 工程保存时,单因子插值结果(FactorGridResult)以 JSON 信封持久化:
legacy 工程内联 `parameters{grid_x, grid_y, grid_z}` 经
`from_legacy_task_parameters` 读入(nodata 的 None/NaN/±Infinity 三编码都归一
为 float32 NaN),`to_descriptor` / `to_legacy_dict` 写出(strict JSON,非
finite 一律 null)。本 PR 把这条读写回路移植到 Qt-free C++:

- **Python 写的 factor grid JSON,C++ 读回 grid_z 与 statistics 一致**——C++
  `from_legacy_task_parameters` 解析 Python 冻结的 parameters/legacy JSON,
  逐格 float32 位级相等、statistics 逐字段相等;
- **反向亦然**——C++ `to_descriptor`/`to_legacy_dict` 输出与 Python 冻结输出
  语义相等(键集、类型身份 int/float/null/bool、声明键序、位级 double),
  且 C++ 读回自己写的 legacy JSON 与 Python 引擎读回路径产出一致的
  grid/statistics/algorithm_id。

不做(见 `18-decisions.md` D3/D5/D6):NPZ zip/.npy 容器、from_constrained_idw_dict、
工程 live-cache/目录层、sqlite/catalog。

## Oracle 案例:45(30 成功 + 15 错误)

成功面覆盖:双 nodata 编码(None 与 NaN/±Infinity)、float32 舍入/溢出
(1e40→NaN)/次正规/bool 数值化、metadata 描述符合并(update 位置语义、两参
get、`is not None` 门控、n_points 的 `len(or [])` 回退、n_break_lines 三层
默认)、crs/unit 优先级与空串显式、provenance 原样透传(含非字符串
run_ref/source_refs 元素)、boundary 环、单格/矩形/1x1、3-D 与平坦列表
reshape、NaN backend("nan")。
错误面冻结 Python `str(exc)` 全文 + 异常类:KeyError×3、空轴、非 finite 轴、
形状不符 ×3(2-D/平坦/3-D 全维)、boundary 非 finite、2-D 轴、非列表轴
TypeError×3、`dict("abc")`。
