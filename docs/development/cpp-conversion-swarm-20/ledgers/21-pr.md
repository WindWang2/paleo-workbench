# CONV-21 — prediction 契约核簇（postprocess / spatial_result / input_contract / model_package 纯半）

## 用户流程（本切片验收）

M9 剩余中最适合 oracle 冻结的纯核：`paleo_workbench/prediction/` 下四个模块中不依赖 catalog/inference/geoviz/文件编排的纯契约半，全部落入既有 `libs/prediction`（CONV-13 已建），Qt-free、运行时无 Python：

- **postprocess**：相邻预测区段合并 + 地层顶界硬边界拆分 + `merged_sample_count` 语义 + `_display_probability` 半偶舍入/钳制 + `resolve_formation_boundaries`（well tops 文件 + LAS 属性对象双源、去重、诊断串）。
- **spatial_result**：空间类型探测、polygon/multipolygon 要素提取（NaN 拒收/inf 放行怪癖保留）、vector/interval/raster 契约校验、`bounded_result_summary` 有界化（grid→grid_shape+grid_omitted）、`is_map_compilable`、固定 demo-square 拒收。
- **input_contract**：`parse_input_schema`——`dict(schema or {})` 强转全语义（含 truthy 非 dict 的 ValueError/TypeError 分叉）、双别名归一（required_asset_types/asset_types、required_curves/curves）、dict 值按键迭代怪癖、`_strict_bool`、min_wells 的 `int(... or 0)`（bool 是 int 子类）、`raw` 原样保留。
- **model_package**：manifest dataclass、`load_manifest_dict`（dict/路径双源、strict UTF-8 与逐字 UnicodeDecodeError 文案）、parse/validate 全套、产物存在性与 sha256 校验、生产限制；`register_model_package`（catalog service）不迁。

复用而非重抄：`pwb_ingest` 的 `py_parse_float`/`py_strip`/UTF-8 原语/`split_path_parts`/`parse_well_tops_text`；`pwb_interchange` 的 casefold；`Pwb::Domain` 的 Json 与 `Sha256::of_file`。Unicode `\w` 由生成器冻结 770 个码点范围（`word_char_ranges.inc`）。

## 构建（可选，默认 OFF）

```bash
cmake -S . -B build/conv-21 -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DPWB_BUILD_PLATFORM=OFF -DPWB_BUILD_CONV_21=ON -DBUILD_TESTING=ON
cmake --build build/conv-21 -j
ctest --test-dir build/conv-21 -R prediction   # 2/2
```

`PWB_BUILD_CONV_21=ON` 隐含 CONV-13/14/19；`libs/prediction` 在 CONV-13 块先 add，`Pwb::Ingest/Pwb::Interchange` 为合法前向引用（generate 期解析）。
