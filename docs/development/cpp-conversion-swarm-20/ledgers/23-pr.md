# CONV-23 — workflow/contracts 纯契约层（models / modules / registry / validation / readiness / report）

## 用户流程（本切片验收）

M7 延续：`paleo_workbench/workflow/contracts/` 子包整体移植为新叶库 `libs/workflow_contracts`——这是 workflow 服务层共享的**契约词汇表**（后续 freshness/factor_fusion/map_product 切片都以它为输入），Qt-free、运行时无 Python：

- **models**：pydantic-lite——10 个 BaseModel 等价 struct + 11 个 str-valued 枚举（scoped enum + `to_string`/`from_string` 忠实映射，`X.value` 语义即字符串）+ `model_dump()`/`from_json`/`completeness()`。
- **modules**：14 个模块契约声明——**生成式 `modules_data.inc`**（同 `lower_map.inc` 先例）：生成器把真实 Python `model_dump(mode="json")` 冻结为嵌入 JSON,C++ `build_all_contracts()` 解析为 struct；声明数据可审计、行为原生。
- **registry**：插入序存储 + id 索引、重复 id `ValueError("duplicate contract id: x")`、构造期 `validate_registry`、导航查询、`p0_ids`、函数级 static 默认单例。
- **validation**：边镜像一致性（audit #848 语义）、datarun op 白名单、专家问题完备性——issue 文案逐字。
- **readiness**：元数据就绪评估（绝不加载 artifact 体）;`ProjectView`（Json 成员）复刻 `getattr(o,k,None) or []`/`or {}`/`or ""` 链；per-ref 深度域判定；**`ProductionModelProbe` 显式 seam**(D5)覆盖 `svc is None`/返回 None/抛异常三分支；绝对路径 `Path.exists` 用 `std::filesystem`。
- **report**：两份确定性 Markdown(consultation + gap)——`_cell` 转义、`or "—"`、`True`/`False` 大写布尔、`enumerate` 序号、SECTION_ORDER 过滤、无尾换行；`write_reports` 落盘等价。

## 构建（可选，默认 OFF）

```bash
cmake -S . -B build/conv-23 -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DPWB_BUILD_PLATFORM=OFF -DPWB_BUILD_CONV_23=ON -DBUILD_TESTING=ON
cmake --build build/conv-23 -j
ctest --test-dir build/conv-23 -R workflow.contracts   # 1/1
```

`PWB_BUILD_CONV_23=ON` 隐含 `PWB_BUILD_DATA`(Pwb::Domain)；声明在 data_suite 块之前使隐含开关及时生效。
