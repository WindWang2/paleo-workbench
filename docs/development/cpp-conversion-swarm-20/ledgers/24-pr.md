# CONV-24 — factor_fusion + factor_units 核移植

## 范围

`paleo_workbench/workflow/factor_fusion.py` + `factor_units.py` → `libs/factor_fusion`(`pwb_factor_fusion`,Qt/Python/numpy-free)。

移植：Normalization/FactorEvidence/FusionRule/FusionModel/FusionResult 契约（ctor 校验 + to_dict/from_dict + sha256 fingerprint)、`_aligned_or_raise`(shape/轴/CRS 纪律）、`_fuse_weighted`(membership 加权 + confidence/conflict/margin/variance 传播 + class 归类 + 全 qc)、`_fuse_rule_based`（有序首匹配 + default 类 + rule_hits)、`sensitivity_report`(LOFO)、`factor_units` 全模块（FACTOR_DEFAULTS 91 条 + FACTOR_FAMILIES 6 族 + folded 查找 + unit-vs-values 诊断）。

排除：`register_output`(catalog 写入缝）、FactorGridResult 的 contours/statistics 渲染面。

## 关键设计

- `pwb::factor_fusion::FactorGrid` 独立载体（float32 grid_z 语义 + float64 轴），不复用 conv-18 信封面。
- fingerprint 用 `json.dumps` 默认分隔符 `", "`/`": "`（区别于 conv-08 canonical 紧凑式），浮点 repr 复用 `Pwb::FactorHost::python_repr_double`。
- FACTOR_DEFAULTS/FAMILIES 由真 Python 生成 `factor_units_data.inc`;`.lower()` 走生成的 `units_lower_map.inc`（全 Unicode 映射，1460 条）。
- 规则 ctor 走 `rule_from_rows` 原始行路径——ragged/误型输入直达 Python 校验分支，tuple repr vs list repr 两版文案各归各位。
