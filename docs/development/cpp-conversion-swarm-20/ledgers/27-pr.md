# CONV-27 — mapping_document 行为层（edit session / undo-redo / snapshot / document IO）

## 范围

在 CONV-02 数据核之上迁移文档行为层，专注文档行为、不做 QGIS toolbar：

- `paleo_workbench/mapping/composer/components.py`（431 行，全量）→ `libs/mapping_document` 的 CompositionEditSession + 命令模型 + CompositionFactory + bind_template。
- `paleo_workbench/mapping/layers.py` 的文档操作面（add/remove/reorder/recompute/active/标题/CRS/metadata、set_visible/set_opacity/set_features、bump 助手）→ MapDocumentEditSession（含 VectorMapLayer.recompute_extent 的退化垫宽契约移植）。
- `paleo_workbench/mapping/document_io.py` + `geometry_schema.py` normalize 族（全量）→ document_io 的 features 规范化。
- 文件级 IO（C++ 契约，Python composition 面板是非原子写）：DocumentStore seam、tmp+fsync+main→bak+replace 原子写、v6 恢复表（bak 恢复 / 损坏隔离 `*.corrupt-<ts>` / 不可读不回退）、未知字段诊断（数据永不丢，extras 保真）。
- 统一 data/style/layout 修订 + saved 基线 + dirty state；不可变文档快照（active layer / extent / style / input_version_ids / provenance refs，深拷贝稳定）。
- service 门面（MapDocumentService / CompositionDocumentService）给 UI/Composer/Workflow。

范围外（明确归类）：`native_edit_session.py` / `edit_session_set.py` / `edit_gesture_manager.py`（QGIS 桥编辑域）、`vector_layer.py` VectorEditSession、`edit_delta.py`（矢量会话派生物）、`map_document_snapshot.py`（渲染适配器）——见 27-decisions D-27-01。

## C++ targets

`libs/mapping_document`（Qt-free / QGIS-free，仅依赖 Pwb::Domain）：
- `edit_command.{hpp,cpp}`：DocumentCommand / LambdaCommand / GroupCommand / CommandStack（undo/redo、revision、组、observer；execute 先 apply 后入栈——异常安全同 Python `_execute`）。
- `composition_session.{hpp,cpp}`：ComposerError / UnknownElementError / ElementSpec+SpecProvider / CompositionFactory / CompositionEditSession（add/insert/remove/move/scale/configure/duplicate/lock/visibility/z-order + set_paper/set_title/set_metadata + 分组/回滚 + bind_template）。
- `map_document_session.{hpp,cpp}`：MapDocumentEditSession + DocumentRevisions/SavedRevisions + recompute_layer_features_extent。
- `map_document_snapshot.{hpp,cpp}`：MapDocumentSnapshot / capture / provenance / snapshots_equal。
- `document_io.{hpp,cpp}`：normalize 族 + DocumentStore/StdFileStore + load/save + 恢复表 + 未知字段诊断。
- `document_service.{hpp,cpp}`：两个 service 门面。
- 顶层 CMake option `PWB_BUILD_CONV_27`（默认 OFF，imply CONV-02/data）。

## Product wiring

`MapDocumentService` / `CompositionDocumentService` 是给 UI/Composer/Workflow 的单一 C++ 入口（load 重置历史、save 原子写+锁存、snapshot 钉 revision）。Qt-free 核不依赖 Python；UI 桥切片可在其上直接接线（无 Python 依赖）。

## Remaining Python

- oracle/fixture：生成器与被移植模块（components/layers/document_io/geometry_schema）保留为 oracle。
- legacy/compatibility：composition_panel 等 UI 过渡期继续用 Python 实现（行为由 C++ oracle 冻结）；QGIS 桥编辑域（native_edit_session 等）留待桥切片分支。
- 无 Python-only 残留缺口（本 scope 内）。

- 组/回滚、会话级 set_paper/title/metadata、文档会话历史语义、文件恢复表为 C++ 契约（无 Python 真值），已在 27-decisions 记录依据。

- registry/样式默认值数据不移植（CONV-02 D-10 延续），由 SpecProvider seam 注入。
