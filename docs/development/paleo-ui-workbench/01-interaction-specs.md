# 01 — 交互规格（Storyboards / Wireframe Specifications）

读者：实现者与审查者。每条路径标注验收标准（=测试矩阵 03 的用例来源）。
图例：`[W]` 线框、`[A]` 验收标准。

## S1 多期次时空滑块（StratigraphicTimelineWidget）

位置：综合编修区顶部（MappingStageBar 之下、画布之上），常驻横条。

```
[W] ┌──────────────────────────────────────────────────────────────────┐
    │ ◀ │ 震旦系 │ 寒武系 │ 奥陶系 │▓石炭系▓│ 二叠系 │ … │ ► │ 🧅 │ 👁 │
    │    └────────┘        └─拖拽滑块─┘                          洋葱皮  │
    └──────────────────────────────────────────────────────────────────┘
```

路径 S1-1（拖拽切换）：
1. 用户按住滑块从 石炭系 拖到 奥陶系（中途扫过多个刻度）；
2. 拖拽中：仅刻度高亮跟随（`epoch_scrubbed`），图层不动；
3. 释放：150ms 去抖后 `epoch_committed("奥陶系")` 一次；
4. 差分切换：石炭系期次层 hide、奥陶系期次层 show（底图/井位不动）；
5. horizon 元数据写穿 + 就绪度刷新（复用既有通道）。
[A] 一次拖拽只发一次 commit；`set_layer_visible` 调用数 = 对称差大小（不多不少）；
    画布 `set_layer_snapshot` 收到增量发布（非全量重建信号）。

路径 S1-2（键盘步进）：←/→ 步进；连击 ≤100ms 间隔内不 commit，停顿 150ms commit。
[A] 连击 N 次仅 1 次 commit，目标 = 最后停留期次。

路径 S1-3（洋葱皮对比）：
1. 当前 = 石炭系；点击 🧅 开启；
2. 前一期次（泥盆系）相带边界层以 30% 不透明度叠加显示（置于当前层之上）；
3. 再点 🧅 关闭：恢复该层用户原不透明度与可见性。
[A] 开启/关闭仅触碰 D2 定义的洋葱层集合；当前期次层不透明度不变；
    视觉快照 diff 数值入 04-visual-qa-verification.md。

路径 S1-4（期次无对应层的诚实降级）：某期次无归属图层 → 切换只更新时间轴高亮与
horizon 元数据，状态栏提示"该期次暂无图层"，不报错。

## S2 相带调色板 + 吸色管（FaciesPaletteWidget & FaciesEyedropper）

位置：编图工作台右侧 dock（新注册 workstation dock `facies_palette`）。

```
[W] ┌─ 相带画刷 ──────────────────────────┐
    │ [吸色管💡] [连续赋值 🔗:ON]          │
    │ ── 三角洲 ──────────────── ① ──     │
    │ ▧三角洲平原 ▧分流河道 ▧河口坝 …      │
    │ ── 潮坪 ────────────────── ② ──     │
    │ ▧混合潮坪 ▧砂坪 ▧泥坪 …             │
    │ 装备：分流河道 [拟合度 ▓▓▓░ 83%]    │
    └────────────────────────────────────┘
```

路径 S2-1（装备画刷）：单击格 → 格高亮、底栏"装备：X"；随后在地图数字化闭合一
个面 → 该面自动携带装备相带属性落层（**不弹模态框**）；连续画 3 个面全部自动赋值。
[A] feature_captured 后 0 次模态对话框；3 个新要素属性 == 装备相带；
    每个要素 = 单一撤销命令。

路径 S2-2（吸色管）：激活 💡 → 光标变拾取十字 → 点击地图上既有相带面 →
底栏"装备：被拾取相带（含亚/微相）"，颜色/花纹与源一致，toast 确认。
[A] identify_all 被调用且顶层优先；装备上下文四元组 (facies, sub, micro, level)
    == 源要素；点击空白 → 装备不变 + 提示 toast。

路径 S2-3（数字快捷键）：绘图工具激活时按 `3` → 装备切换到"常用第 3 格"并高亮；
工具退出后按 `3` → 无相带动作（hub 页导航不受影响，见 00 D6 实证）。
[A] 工具激活期：装备变化 1 次；工具未激活：FaciesBrushContext 无变化。

## S3 单因素约束 HUD + 连井剖面联动（ConstraintFactorHUD）

位置：画布右上角浮动只读条（父级=画布容器，不拦鼠标）。

```
[W]                                     ┌──────────────────────────┐
    （主地图画布）                       │ 砂地比 62.4%   坡度 0.8° │
                                        │ 最近井 W-17 相别:分流河道 │
                                        │ 预测置信度 0.81          │
                                        └──────────────────────────┘
```

路径 S3-1（悬浮读值）：光标移动 → 60ms 内 HUD 数值刷新（合并中间点）；
数据缺项显示 `—`。高频抖动光标（1000 点）→ 无卡顿（事件循环无长任务）、
topLevelWidgets 数量不变。
[A] 节流后 handler 调用数 ≤ 移动点数/60ms；内存断言见 03-Matrix。

路径 S3-2（连井剖面联动）：主地图画线（DIGITIZING）时光标靠近井 W-17（容差内）→
已打开的连井剖面视图出现垂直光标线于 W-17 道，联动指示当前层段；离开容差 → 光标
线淡出（300ms 延迟清除，防闪烁）。
[A] publish 事件带 source tag；连井侧 sink 收到 (well_key, md=None)；
    地图自身不因 sink 回写再次 publish（echo 断路）。

## S4 交互式质检修复向导（InteractiveQCHub）

位置：综合编修区 dock（或画布下方面板升级）；双栏 = 问题列表 + 详情/修复区。

```
[W] ┌─ 质检修复向导 ────────────────────────────────────────────┐
    │ [重新检查] 筛选:[全部▼]          12 错误 · 3 警告        │
    │ ┌────────────────────────────────┬──────────────────────┐│
    │ │ ▲ 相带重叠  F12/F30  修复可用  │ 问题：相带重叠(2.3m²) ││
    │ │ ▲ 孤岛相带  F07     修复可用   │ 图层：石炭系-相带     ││
    │ │ ▼ 悬挂断层  L2       —        │ [定位] [高亮]         ││
    │ │                                │ ── 快速修复 ──       ││
    │ │                                │ [吸附合并到相邻优势相]││
    │ │                                │ [沿切线自动延伸闭合]  ││
    │ └────────────────────────────────┴──────────────────────┘│
    └────────────────────────────────────────────────────────────┘
```

路径 S4-1（定位）：双击列表项 → 主地图平滑平移居中（180ms ease-in-out）到问题
bbox（10% pad），问题要素高亮（差分红）。若 QC Hub 悬浮则面板短暂半透明避让。
[A] 末态 extent == bbox+pad；中间帧 ∈[4,12] 且中心单调；历史记录恰 1 条。

路径 S4-2（一键修复-碎多边形）：选中"孤岛相带 F07" → 点 [吸附合并到相邻优势相] →
F07 并入共享边最长的相邻相 F03（几何 union，属性取 F03）→ 列表刷新该项消失 →
Ctrl+Z 一次完全复原（F07 回来、F03 几何复原）。
[A] 修复后 1 条撤销命令可整体回滚；合并决策 == 共享边最长规则；UI 无模态框。

路径 S4-3（一键修复-未封闭边界）：[沿切线自动延伸闭合] → 端点沿切线延伸至进入容差
后闭合；不可修（超最大延伸距离）时按钮禁用 + tooltip 原因。
[A] 同 S4-2 撤销粒度；禁用态可达且带原因。

路径 S4-4（来源聚合）：hub 聚合 cartographic_qa 15 规则族 issue + topology
checker issue（统一 dict 形状），任一来源刷新即增量更新列表。

## S5 全键盘编图流（WorkstationKeyBindingManager + FSM）

位置：画布底部常驻提示条（Keybinding HUD），随 FSM 状态换提示。

```
[W] ┌────────────────────────────────────────────────────────────┐
    │ 画布 …                                                      │
    ├────────────────────────────────────────────────────────────┤
    │ [数字化中] Space 平移 · Tab 下一要素 · Ctrl+D 吸属性 · Esc 取消│
    └────────────────────────────────────────────────────────────┘
```

路径 S5-1（全键盘 30 分钟连续编图剧本）：数字键装备相带 → 画布画三个面（无鼠标
选菜单）→ Tab 循环选中 → Ctrl+D 吸取属性 → Z/X 调整视野 → Esc 安全退出。
全流程 0 模态框、0 鼠标菜单依赖。
[A] 见 03-Matrix M5 端到端用例；每步 FSM 状态迁移符合 02 图。

路径 S5-2（状态提示同步）：进入 TIME_TRAVELLING → 提示条变为
"←→ 步进 · 🧅 洋葱皮 · Esc 返回编图"；INSPECTING_QC → "↑↓ 选择 · Enter 定位 ·
F 修复"。
[A] 提示条文本 == 状态查找表；状态迁移即刷新（信号驱动，非轮询）。
