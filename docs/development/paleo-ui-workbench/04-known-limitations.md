# 04 — 已知限制（本期不支持）

诚实边界。每条附原因与（若适用）后续路径。审查时对照本表，不算缺陷。

## 时间轴 / 洋葱皮
1. **洋葱皮仅一层前期次**（D2）：多期叠加（N-1/N-2/N-3 递减透明度）留待下期；
   噪声收益比差。
2. **洋葱皮轮廓非纯线描**：以 30% 不透明度整层叠加呈现，不做 renderer 级
   "仅边界线"重渲染（需桥端 renderer 协议扩展，超出纯 Python 边界）。
3. **无名年代 horizon 不参与年代排序**："第 N 层序界面" 无法映射 Ma，按声明序
   追加（D1）；如需混合排序需引入显式 age 元数据字段。
4. **内置年代方案为显显示用**：不解析地质体自动定年；不校验 horizon 命名规范。
5. **timeline 不改变 user_vector_layers 归属存储**：层→期次归属来自分类器
   （名称/标签约定），未新增持久化 schema 字段（避免迁移）；工程文件零变更。

## 调色板 / 吸色管
6. **吸色管不取"像素色"**：拾取的是要素属性+分类渲染色（数据正确性优先）；
   不支持从位图底图吸 RGB。
7. **常用 1-9 为固定前 9 格**：本期无自定义"常用"钉选（无持久化 UI）。
8. **D6 若实证为双触发** → 降级 Shift+1…9（登记 00-D6-rev1 时同步本表）。

## HUD / 联动
9. **井数 >5000 时最近邻线性扫描**（D7）：O(n)/刷新；实测井区规模内可接受，
   >5000 需空间索引（后续 ticket）。
10. **相别分歧/置信度依赖数据在场**：无解释/方差数据 → 显示 `—`，不估算。
11. **连井剖面联动为井位级竖带指示**（md 不参与）：引擎 geoviz_cross_well
    无逐道 crosshair API（vendored 子模块，纯 Python 边界外）；竖带按
    last_well_names 序取井道中心 x 近似。深度段对齐投影需时深标定与层段
    插值，超本期范围。
12. **HUD 不支持触屏/高DPI 拖拽分离**：4K 150%+ 缩放下 HUD 字号不随 DPR 三档
    自适应（跟随全局字体，单档）。

## QC Hub / QuickFix
13. **fallback 渲染栈的高亮=选中集+描边状态**：非逐像素描红（native 栈走桥
    highlight_checker_errors；fallback 无逐要素 overlay 通道）——差分"红线"在
    fallback 下以选中高亮呈现，视觉回归断言按栈类型区分。
14. **切线闭合不处理自相交**：延伸产生自相交时判不可修（禁用+原因），不自动
    打结重组（拓扑复杂度超期）。
15. **QuickFix 覆盖两类规则**（碎多边形合并 / 未封闭边界闭合）；其余 15 规则族
    issue 仅定位+说明，无修复动作（逐步扩展 QUICK_FIX_ACTIONS）。
16. **修复不可跨图层**：合并双方须同层（跨层合并需图层对齐语义，未定义）。

## 键盘 / FSM
17. **Tab 循环仅当前图层选中集**：跨图层循环涉及选中权威（SelectionContext）
    写路径扩展，下期。
18. **Space 平移依赖画布 pan 能力**：native 栈=QGIS pan 工具；fallback 栈=拖拽
    pan 预览（无惯性格式）。
19. **快捷键不提供用户自定义映射 UI**：方案固定（D5 表）；注册表机制已支持
    运行时替换，UI 留待下期。
20. **FSM 为投影层**：不持久化、不入工程文件；崩溃恢复不还原 mode（IDLE 起步）。

## 键盘 / Esc 链（补遗）
23. **Esc 链与既有取消动作的分工**：数字化手势进行中的 Esc 仍由既有 map
    cancel 动作（手势取消）先行；无手势期由 M5 管理器接管（退出工具 →
    关闭向导 → IDLE）。两级在同一键上按状态接力，不做手势探测。
