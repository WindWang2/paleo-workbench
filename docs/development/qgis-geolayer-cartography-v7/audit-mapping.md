## 4. RENDERING & COMPOSER

### 4.1 Layer rendering today (three render paths)

1. **QPainter fallback canvas** — `FallbackMapRenderBackend` (map_render_backend.py:619). Per-data-revision numpy parse into `_PreparedLayer` (:307, flat concatenated coordinate arrays), per-frame vectorized world→screen, bbox culling (:1183), pixel-grid LOD + vertex budget (:1243-1281), batched points/categorized/graduated grouping (cap 50k, :1423), labels deferred to GUI thread as `_LabelSpec` plain data (#822, :231). Scalar grids composited from `renderer_payload.rasterize()` (:1644); raster sources stretched onto extent (:1669). CRS reprojection via pyproj per (layer, revision) (:1038); unreprojectable rasters warned, never silent (:1020).
2. **Native QGIS canvas** — `QgisMapRenderBackend` (:1719). `_qgis_snapshot` (:2024) encodes: scalar_grid → GeoTIFF mirror path (kind raster), raster_source → path, vectors → WKT features + flattened style + `scale_range`; **incremental feature-delta shipping** (#932, :2139-2156: changed/removed features only when the bridge provably holds the previous revision; stale-delta rejection → full reship :1865). Rendering is async w/ generation guard; `export_vector` gives true SVG/PDF through QGIS (:1998). Style on the wire: `_flatten_qgis_style` (:2197) promotes `style["qgis_style"]` (`renderer_xml`/`labeling_xml`) to top keys, converts label sizes px→pt and halo mm (unit parity #1025/#1102).
3. **SVG string renderers** — `renderers.py` registry used by the composer (and any vector export): `SingleSymbol/Categorized/Graduated/Grid/Contour/WellSymbol/Annotation`. GridRenderer embeds a base64 PNG (rasterize_rgba → PIL flipud) (:527-552). `RenderContext` is the single unit-conversion authority (px/mm/pt at 96-DPI logical baseline, #1025/#1103); the QGIS backend does NOT use RenderContext (converted at the wire instead, documented :56-62).

**RGBA mirror generation chain (factor grids):** `FactorGridResult` → `GridMapLayer` (holds z/x/y + ramp) → `to_snapshot()` wraps a `_ScalarPayload` duck-type whose `rasterize()` returns H×W×4 RGBA (layers.py:291-315) → fallback paints QImage; QGIS path `ScalarRasterMirrorCache.ensure()` writes a georeferenced 4-band Byte GeoTIFF into `/vsimem/` (or disk dir for diagnostics) keyed by (data_revision, style_revision, payload revisions), with deferred unlink only after the bridge stops referencing it (scalar_raster_mirror.py:52-94, WriteRaster interleaved buffer :180).

**Style authority:** flat `VectorStyle` dict (map_styles.py) is the compat/fallback vocabulary; `QgisStylePayload` (qgis_style.py:73, schema v1, `renderer_xml` + optional PAL `labeling_xml` + `revision`) is the professional authority stored nested under `style["qgis_style"]`; migration via native `legacy_style_to_renderer_xml` (:140). `geological_style_library` adds 12 science-bound `StyleEntry`s (binding records which field/classes a style renders).

- **Component graph:** `MapCompositionDocument` (mm paper A5–A0, dpi) + flat list of `ComposerElement` (x/y/w/h mm, z_index sort on add). Schema v2 with forward-compat: unknown element types carried as TEXT + `_raw_element_type` (models.py:114-139); unknown top-level keys tolerated on load.

- **Edit semantics:** `CompositionEditSession` command pattern (add/insert/remove/move/scale/configure/duplicate/lock/visibility/z-order), monotonic `revision`, locked elements refuse mutation everywhere (components.py:110-369).
- **Templates:** `TEMPLATE_LIBRARY` — single_factor, contour, heatmap, well_location, seismic_interpretation, isopach, lithofacies, paleogeographic, comprehensive; each declares elements + `style_bindings` (colormap, renderer, line colors) + `data_bindings` (e.g. `factor.colorbar`, `paleo.water_depth`, `interpretation.misfits`) resolved at bind time by `bind_template` against host context (templates.py:120-324, components.py:377-403). - **Rendering:** `MapComposerRenderer.render_to_svg` — mm-unit SVG viewBox; MAIN_MAP/INSET_MAP render MapDocuments through the shared `DEFAULT_RENDERER_REGISTRY`; LEGEND auto-extracts `LegendItem`s from the main map (renderer.py:1265-1298); charts are pure-geometry SVG (bar/hbar/line/scatter/pie/donut/histogram/rose with compass azimuth semantics).
- **Export pipeline:** `composer/export.py` — SVG (physical mm attrs), PNG (QSvgRenderer replay + setDotsPerMeter), PDF (QPdfWriter exact mm page, vector SVG replay). Pixel budget guard for A0@600dpi in `layout_export.py:145`.

GeoPDF flag supported (:358).

### 4.3 Workspace orchestration (mapping_workspace)

3 stages (`MappingStage`), union layer tree ("One Layer Identity": a layer appears once in the QGIS tree; stage switch = group-visibility delta, never tree rebuild). `LayerGroupController` holds a *desired* tree (templates + membership + user placements) and incrementally reconciles to the QGIS tree via bridge group API (`upsert_group/move_layer_to_group/set_group_visibility/remove_groups_except/apply_tree_placements`), with echo suppression and role-validated user drags (`observe_tree_nodes` rejects semantic mismatches, layer_group_controller.py:543). Freshness (`MappingDependencyService`) reads Catalog version/run lineage only; maturity draft→published orthogonal to stage; `compilation_input_set` pins Phase-3 evidence versions.

## 7. KEY FINDINGS (summary)

**Architecture.** Clean layering: pure-data domain (mapping_workspace, no Qt/QGIS) → document model (layers.py) → immutable snapshot seam (map_render_backend.py) → two swappable canvas backends (QPainter fallback / native QGIS) with identical contracts; composer is a separate pure-data component graph with declarative data/style bindings and two export engines (SVG/QPdfWriter composer vs transient native QgsLayout, all-or-nothing). Host keeps transaction authority everywhere (edit sessions + DataVersion provenance); QGIS is only ever a mirror/renderer.

**Duplication hotspots.** (1) THREE point-in-polygon ray-casters (polygonization :61, interpolator :595, map_interaction :86). (2) TWO edge/segment graph-stitching implementations (contouring :132, polygonization :180). (3) THREE simplification regimes (RDP :67, unused bridge `simplify`, renderer pixel-LOD :1243 — the last is intentionally separate). (4) FOUR spatial indexes (FeatureQueryIndex, FeatureSpatialIndex, renderer bbox culling, cKDTree). (5) TWO geometry-repair entry points (topology.repair_invalid_geometry vs geometry_service.make_geometry_valid). (6) FIVE extent builders. (7) Two clip-to-ring skeletons (line vs polygon). (8) Two complete style vocabularies (flat VectorStyle + QgisStylePayload XML) bridged only at `_flatten_qgis_style`. (9) Merge/split deliberately dual-path (QGIS preferred / shapely fallback) — good pattern, but the only bridge geometry ops actually used are union/split_by_line/make_valid; **buffer, clip, difference, offset_curve, densify, simplify, smooth, multipart↔singlepart, intersection, is_valid are exposed by the bridge and unused**.

**What's missing / gaps.** No producer for `FACTOR_UNCERTAINTY`, `FACTOR_QC`, `ANALYSIS_AID` layers (variance_grid computed+persisted, style exists, routing exists — no builder). `LayerType` (runtime) ↔ `LayerRole` (science) have no formal binding (convention + membership metadata only). No contour→polygon filling. No native counterpart for timescale/stat-chart/legends/colorbar/inset in QgsLayout export (forces composer fallback for any template using them). Raster reprojection (warp) intentionally out of scope for fallback (warned only). Readiness geometry check is naive (non-empty coordinates) while a real shapely validator exists in TopologyService.
