# 06 — QGIS SDK API verification (vendored headers)

Verified against `main/third_party/qgis` @ `cpp-migration-plan-v1-568-g192422c60`. **This is a QGIS 4.0-generation API tree** — several 3.x APIs do not exist. All signatures below quoted from headers.

## Confirmed present

- `QgsProcessingRegistry` (core/processing/qgsprocessingregistry.h): `addProvider(QgsProcessingProvider*)` (transfer, auto `load()`), `removeProvider`, `providers()`, `algorithms()`, `algorithmById(QString)`, `createAlgorithmById(id, configuration)` (caller deletes), `addAlgorithmAlias`. Signals: `providerAdded/Removed`, `parameterTypeAdded/Removed`. **No `algorithmAdded` signal.**
- `QgsProcessingProvider` (qgsprocessingprovider.h): pure virtual `id()`, `name()`, protected `loadAlgorithms()` calling protected `addAlgorithm(QgsProcessingAlgorithm*)`. Also `helpId()`, `longName()`, `versionInfo()`, `load()/unload()`, `refreshAlgorithms()`, `algorithms()`, signal `algorithmsLoaded()`.
- `QgsProcessingAlgorithm` (qgsprocessingalgorithm.h): pure virtual `name()`, `displayName()`, protected `initAlgorithm(configuration)`, `createInstance()`, `processAlgorithm(parameters, context, feedback)`. Virtual `group()/groupId()`, `flags()` (`Qgis::ProcessingAlgorithmFlags`, default SupportsBatch|CanCancel), `shortHelpString()`, `checkParameterValues()`. Main-thread convenience `run(...)`; background = `prepare()` → `runPrepared()` → `postProcess()`. Protected `addParameter(def, createOutput)`, `parameterAs*` helpers. **No static `execute()`.**
- Parameters (qgsprocessingparameters.h): Boolean :1958, Crs :1986, Extent :2018, Point, Number :2429 (`Qgis::ProcessingNumberParameterType::Integer/Double`), Enum :2970, String :3080, VectorLayer :3267, RasterLayer :2910, Field :3374 (parentLayerParameterName; 4.0 `Qgis::ProcessingFieldParameterDataType`), FeatureSource :3482, MultipleLayers, FeatureSink :3638, VectorDestination :3740, RasterDestination :3816, FolderDestination :3946, Band, File, Distance, Expression, DateTime…
- Outputs (qgsprocessingoutputs.h): `QgsProcessingOutputVectorLayer/RasterLayer/Number/String/Boolean/Folder/File/MultipleLayers/Variant/Html…`.
- `QgsProcessingContext` (qgsprocessingcontext.h): `setProject`, `transformContext`, `expressionContext`, `addLayerToLoadOnCompletion(id, LayerDetails)`, `takeResultLayer`, `temporaryLayerStore`, `pushToThread`, `copyThreadSafeSettings`, `setMaximumThreads`, log level. **No `invalidLayerBehavior`** (3.x API).
- `QgsProcessingFeedback` (qgsprocessingfeedback.h) : QgsFeedback: `setProgress(double)`/`isCanceled()`/`cancel()` from qgsfeedback.h (signals `progressChanged(double)`, `canceled()`); plus `setProgressText`, `reportError`, `pushWarning/pushInfo/pushConsoleInfo`. `QgsProcessingMultiStepFeedback(steps, baseFeedback)` + `setCurrentStep(i)` defined in the same header (no separate file).
- `QgsTask` (core/qgstaskmanager.h): ctor `(description, flags)`; `TaskStatus{Queued,OnHold,Running,Complete,Terminated}`; `TaskFlag{CanCancel=1<<1, CancelWithoutPrompt, Hidden, Silent}`, **`AllFlags == CanCancel`**; `cancel()` (override must call base), `hold()/unhold()`, `addSubTask(sub, deps, subDependency)`, `waitForFinished(timeout)`, protected `run()`, `finished(bool)` (**main thread, not a signal**), `isCanceled()`, protected slot `setProgress(double)`; signals `progressChanged/statusChanged/begun/taskCompleted/taskTerminated`.
- `QgsTaskManager`: `addTask(QgsTask*, priority)` / `addTask(TaskDefinition{task, dependentTasks}, priority)`; `tasks()`, `task(id)`, `taskId(task)`, `activeTasks()`, `countActiveTasks()`, `cancelAll()`, `dependenciesSatisfied`, `threadPool()` (QThreadPool, since 3.34); signals `taskAdded`, `statusChanged(long,int)`, `progressChanged(long,double)`, `allTasksFinished`, `countActiveTasksChanged`, `taskAboutToBeDeleted`. **No `taskStateChanged`/`finally` signals; no `setDependentTask`** (use TaskDefinition dependencies).
- `QgsApplication::instance()`, `static processingRegistry()` (qgsapplication.h:992), `static taskManager()` (:750); init via `QgisRuntime::acquire()` (already in bootstrap).
- `QgsProcessingAlgRunnerTask` (core/processing/qgsprocessingalgrunnertask.h): ctor `(const QgsProcessingAlgorithm*, QVariantMap, QgsProcessingContext&, QgsProcessingFeedback*, Flags)`; clones + prepares in ctor (main thread), `runPrepared` in task thread, `postProcess` in `finished()` (main thread); signal `executed(bool, QVariantMap)`.
- Batch helper: `qgsprocessingbatch.h`; model execution: `models/qgsprocessingmodelalgorithm.h`.

## Confirmed absent (do not call)

`QgsProcessingRegistry::algorithmAdded`; `QgsProcessingAlgorithm::execute()` static; `QgsProcessingContext::invalidLayerBehavior`; `QgsTaskManager::taskStateChanged/finally`; `QgsTask::setDependentTask`; `QgsProcessingModelerDialog` (renamed `QgsModelDesignerDialog`, gui); `python/plugins/processing` (no python dir at all); core processing history provider (gui-only, Python-coupled — not reused; Paleo provenance/catalog remains the history authority).
