# Phase 18b + 18c Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire real LAS/SEGY into prediction canvases via `input_refs` (18b), then produce a deterministic editable map draft from project state (18c).

**Architecture:** Pure functions stay in `paleo_workbench/pipeline/` (no Qt). Prediction pages receive the full `ProjectDocument` (or resources + tasks) and resolve canvas data with `VizAdapter` when bound; unbound tasks keep mock converters. Map draft compiler builds GeoJSON-like facies + well overlays and appends `PaleoMapDocument`; mapping toolbar triggers it.

**Tech Stack:** Existing `VizAdapter`, `MockPredictionAdapter`, `create_mock_factor_map`, mapping document schema, PySide6 pages, pytest/pytest-qt.

**Spec:** `docs/superpowers/specs/2026-07-10-e2e-real-data-pipeline-design.md` (§18b, §18c)  
**Depends on:** Phase 18a (`pipeline.bootstrap`, sample project).

**Non-goals:** Real ML, multi-well cross-plots, vendor DFB import, QC automation.

```python
"""18b: bind project resources to PredictionTask.input_refs."""

from __future__ import annotations

from typing import Any

from paleo_workbench.prediction.adapters import MockPredictionAdapter
from paleo_workbench.project.models import PredictionTask, ProjectDocument

WELL_KEY = "well_log_resource_ids"
SEISMIC_KEY = "seismic_resource_ids"


def suggest_assets_for_demo(
    project: ProjectDocument,
    *,
    max_wells: int = 5,
    max_seismic: int = 1,
) -> dict[str, Any]:
    wells = sorted(
        (r for r in project.resources if r.type == "well_log"),
        key=lambda r: (r.name or "", r.id),
    )
    seismics = sorted(
        (r for r in project.resources if r.type == "seismic"),
        key=lambda r: (r.name or "", r.id),
    )
    return {
        "well_log_ids": [r.id for r in wells[:max_wells]],
        "seismic_ids": [r.id for r in seismics[:max_seismic]],
    }


def bind_prediction_assets(
    project: ProjectDocument,
    task: PredictionTask,
    *,
    well_log_ids: list[str] | None = None,
    seismic_ids: list[str] | None = None,
) -> PredictionTask:
    """Mutate task.input_refs; filter to existing resource ids of correct type."""
    by_id = {r.id: r for r in project.resources}
    refs = dict(task.input_refs or {})

    if well_log_ids is not None:
        refs[WELL_KEY] = [
            rid
            for rid in well_log_ids
            if rid in by_id and by_id[rid].type == "well_log"
        ]
    if seismic_ids is not None:
        refs[SEISMIC_KEY] = [
            rid
            for rid in seismic_ids
            if rid in by_id and by_id[rid].type == "seismic"
        ]
    task.input_refs = refs
    return task


def ensure_demo_prediction(
    project: ProjectDocument,
    *,
    seed: int = 0,
) -> PredictionTask:
    """Ensure one mock prediction task exists and is bound to demo assets.

    If the latest task already has well/seismic refs, return it.
    Else create via MockPredictionAdapter (empty factor ids) and bind suggest_assets.
    """
    suggestion = suggest_assets_for_demo(project)
    if project.prediction_tasks:
        task = project.prediction_tasks[-1]
        has_refs = bool(
            (task.input_refs or {}).get(WELL_KEY)
            or (task.input_refs or {}).get(SEISMIC_KEY)
        )
        if has_refs:
            return task
        return bind_prediction_assets(
            project,
            task,
            well_log_ids=suggestion["well_log_ids"],
            seismic_ids=suggestion["seismic_ids"],
        )

    task = MockPredictionAdapter().run(project, factor_map_ids=[], seed=seed)
    return bind_prediction_assets(
        project,
        task,
        well_log_ids=suggestion["well_log_ids"],
        seismic_ids=suggestion["seismic_ids"],
    )
```

### Task 4: `compile_map_draft` pure compiler

**Geometry rules (deterministic, demo-grade):**

1. Resolve horizon: arg → last compilation_run.target_horizon → stratigraphy.target_horizon → `"未指定层位"`.
2. Resolve prediction task: by id or latest task.
3. Facies polygons from `result_summary.predicted_regions` (if any): for each region index `i` of `n`, place a unit square in a grid:
   - `x0 = 114.0 + (i % cols) * 0.05`, `y0 = 22.5 + (i // cols) * 0.05`, side `0.04`
   - Feature:

```python
{
  "type": "Feature",
  "properties": {
    "name": region["facies"],
    "facies": region["facies"],
    "probability": region.get("probability"),
    "region_id": region.get("region_id"),
  },
  "geometry": {
    "type": "Polygon",
    "coordinates": [[
      [x0, y0], [x0+side, y0], [x0+side, y0+side], [x0, y0+side], [x0, y0],
    ]],
  },
}
```

4. If no regions: one placeholder polygon `"未分类"` at origin cell (still editable).
5. Wells: from factor tasks' `parameters.sample_points` if present (`well`/`x`/`y`); else synthetic from `stratigraphy.applicable_wells` or well_log resource stems:

```python
{"name": well_name, "lng": 114.0 + i * 0.02, "lat": 22.6 + (i % 3) * 0.01}
```

6. `view_state = {"generator": "deterministic-map-draft-v1", "is_demo_draft": True, "seed": seed}`
7. `map_chrome = {"title": name, "legend_facies": [...unique facies...]}`
8. Append to `project.paleomap_documents`; if `compilation_runs`, set `active_paleomap_document_id` on last run.
9. Raise `ValueError` only if you choose strict mode — **prefer always produce a draft** so UI never dead-ends (spec said raise if insufficient; for demo UX produce placeholder). **Decision: always produce draft** (placeholder polygon if empty). Document in code.

Determinism: same seed + same region list → same geometry (seed may offset base coords slightly: `base_x = 114.0 + (seed % 10) * 0.001`).
