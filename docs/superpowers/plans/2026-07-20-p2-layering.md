# P2 分层修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 斩断 viz→ui 与 resources→workflow 反向依赖，统一 export 归属，清理包内函数内 import，恢复 `ui → viz/workflow/resources/mapping → project` 依赖方向。

**Architecture:** 机械移动 + import 路径更新。4 个 helpers 模块从 `ui/pages` 下沉到 `viz/`（无兼容 shim，全部调用点改新路径）；`ui/tokens.py` 本体上移为 `paleo_workbench/tokens.py` 并在原路径留 `import *` shim（73 处生产引用不动）；`record_export` 移入新模块 `project/artifacts.py` 并删除 `workflow/export.py`；49 处包内函数内 import 中 42 处上移顶层，7 处确需懒加载的加注释保留。

**Tech Stack:** Python 3.12, PySide6, pydantic, pytest + pytest-qt。

**Spec:** `docs/superpowers/specs/2026-07-20-paleo-workbench-refactor-design.md`（P2 节）

## Global Constraints

- 只改结构与 import 路径，不改功能行为与 UI 文案。
- 测试文件只允许修改 import 路径（本计划明确列出的 7 个测试文件），不得改测试逻辑与断言。
- 测试运行命令统一为 `.venv/bin/python -m pytest <path> -q`。
- 全量测试数在整个 P2 保持 **1109 passed**（不增不减；基线为分支起点 933d769 的实测值）。
- 不保留旧路径兼容 shim 的两处例外：`ui/tokens.py`（`import *` shim，因 73 处生产引用 + 18 个测试文件）；其余移动均直接更新全部引用点。
- 移动的文件内容逐字保留，仅改计划明确指定的 import 行。
- 明确不动的懒加载（第三方重型/可选依赖）：所有函数内 `import geoviz/lasio/segyio/rasterio/PIL/pandas/shiboken6/numpy` 等保持原样。

调查结论（两份诊断报告，已验证）：
- `mapping_helpers.py`/`prediction_helpers.py`/`geoviz_preview_host.py` 不 import 任何 `paleo_workbench.ui.*`；`seismic_prediction_helpers.py` 仅第 5 行 import prediction_helpers。`viz/hosts/` 已有 PySide6 顶层 import 先例。
- `field_value` 在 `mapping_helpers.py:6` 与 `prediction_helpers.py:8` 重复定义（逐字相同）。
- `record_export` 只依赖 `project.models`；外部引用仅 5 处 import 行（workflow/qc_report_export.py:9、resources/export_service.py:18、4 个测试文件）；`workflow/__init__.py` 不导出它。
- `ui/tokens.py` 纯常量 + `format_size` 函数，无 PySide6 依赖；无测试 monkeypatch tokens。
- AST 循环分析：preview_provider ↔ fallback_preview 存在真实循环（fallback_preview 顶层 import preview_provider），其余函数内包内 import 上移均安全。
