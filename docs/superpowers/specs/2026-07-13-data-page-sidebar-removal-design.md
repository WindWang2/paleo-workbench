# 数据页信息侧栏移除设计

## 目标

在数据页隐藏左侧重复的信息侧栏，释放横向空间给资源树、列表与预览阅读器；其他页面维持现有侧栏。

## 范围

- 在数据页隐藏应用壳层的 `TextSidebar`；切换到其他页面时恢复显示。
- 资源、成果和异常统计继续由页面顶部摘要卡展示。
- 当前文件的名称、类型、格式与路径继续由右侧阅读器标题、元信息和检查器展示。
- 导入、重扫、移出项目及打开目录继续保留在现有工具栏。

## 交互与布局

数据页主体从“信息侧栏 + 资源树 + 文件列表 + 阅读器/检查器”调整为“资源树 + 文件列表 + 阅读器/检查器”。不新增折叠控件，也不改变既有数据操作或选择逻辑。侧栏的现有数据上下文仍可更新，但在数据页不占据界面空间。

## 验证

- 进入数据页时 `TextSidebar` 不显示且不占布局宽度。
- 离开数据页时 `TextSidebar` 恢复显示并呈现目标页面的上下文。
- 导入、选择、阅读器预览及检查器信息保持可用。
- 现有数据页布局测试更新为新的分栏结构。
