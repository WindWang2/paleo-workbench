# 富文本文件禁用内置预览设计

## 目标

消除导入 HTML 等富文本文件后，Qt 在 UI 线程解析完整文档造成的卡顿。

## 行为

- .html、.htm、.md 和 .markdown 文件仍可正常导入、分类、检索、查看路径及移出项目。
- 这些格式不再构造或渲染内置富文本预览。
- 选中此类文件时，阅读器显示“此类文档不提供内置预览，可使用打开目录定位文件”。
- 不改变 PDF、文本、表格、图像、地理栅格、JSON 与专业数据格式的预览行为。

## 验证

- HTML 预览结果为消息模式，不携带完整 HTML 内容。
- 超大 HTML 文件的预览构建不读取或传递其全文。
- 其他预览格式维持现有行为。
