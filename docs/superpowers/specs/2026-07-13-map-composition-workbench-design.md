# 编图工作台、参考地图与性能优化设计

> **日期：** 2026-07-13  
> **状态：** 已确认，待实现规划  
> **页面：** 编图（`MappingPage`）  
> **前置：** 项目基准坐标、现有 `MapEditScene` / `map_edit_core`

## 目标

将编图页面重构为以画布为核心的专业工作台，使复杂相带边界的编辑、拓扑问题处理、带坐标参考图对照及单因素判断在同一界面完成。所有参与编图的数据必须转换到项目基准坐标。

## 已确认的体验

默认采用平衡工作台：左侧管理可编辑图层与捕捉状态；中间为主编辑画布；右侧持续呈现参考地图；底部是可折叠、可调高的工作区。用户可切换至画布优先模式以编辑复杂曲线。

底部工作区包含三个标签页：

- **属性：** 当前要素的属性、几何摘要和编辑记录。
- **拓扑问题：** 问题类别、涉及要素与“定位”操作；普通警告允许保存，无效几何禁止保存。
- **单因素参考图：** 同坐标系的缩略卡片。选中后与主画布同步范围、十字定位与坐标读数；可一键提升为主画布叠加层。

## 坐标与参考图数据流

```
栅格 / 带配准影像 / GeoJSON / Shapefile / 其他 GDAL 支持格式
  → GDAL 读取 CRS 与地理变换
  → 重投影至项目基准坐标
  → 参考图层描述、栅格概览或矢量显示缓存
  → 主画布叠加 / 右侧独立参考 / 底部单因素图
```

新增持久化的参考图层描述，包含稳定 id、源路径、图层类型、源 CRS、项目基准 CRS、转换信息、可见性、透明度、显示顺序、捕捉参与状态及缓存版本。它随 `PaleoMapDocument` 的编图草稿保存。

缺失坐标或无法转换到项目基准坐标的数据不得进入编辑画布；界面须明确报告原因。栅格参考图仅用于对照，不参与拓扑；矢量参考层可设为“仅显示”或“参与捕捉”。

## 编辑与拓扑

保留现有选择、移动、节点、绘制、捕捉、撤销/重做和草稿保存机制。所有可编辑矢量图层共享项目坐标，因而可参与节点捕捉与相邻关系判断。

在结束节点拖动、完成线绘制和保存前，后台刷新受影响要素的拓扑结果。自交、退化环等无效几何阻止保存；相邻重叠、缺口和普通自交警告展示在问题列表中并可定位，但默认不阻止草稿保存。每次后台结果携带编辑版本，过期结果不得覆盖更新后的场景。

## 性能架构

- 以视窗为边界：仅构建和绘制可见范围的矢量与注记。
- 用空间索引筛选命中、框选和捕捉候选；鼠标移动热路径通过 `map_edit_core` C++ 门面处理，避免 Python 对所有顶点逐点扫描。
- 栅格使用 GDAL 概览/金字塔与按需瓦片缓存；矢量显示缓存以数据版本、基准坐标系、样式和缩放级别为键。
- 平移或缩放期间优先显示简化几何，操作停止后异步补绘高精度显示；编辑与保存始终使用原始精度坐标。
- GDAL 转换、概览构建、缓存准备和拓扑批检在后台线程运行，UI 线程只协调状态和渲染不可变结果。

## 组件边界

| 组件 | 职责 |
|---|---|
| `ReferenceLayerService` | GDAL 读取、CRS 校验/转换、缓存键与后台任务编排 |
| `ReferenceLayerModel` | 参考图层的持久化描述、显示与捕捉配置 |
| `MapReferencePanel` | 右侧参考图浏览、透明度、显隐与叠加控制 |
| `MapFactorShelf` | 底部单因素卡片、同步视窗和提升为叠加层 |
| `MapTopologyIssuePanel` | 问题过滤、定位和保存前摘要 |
| `MapEditScene` + `map_edit_core` | 场景编辑、空间索引、命中/捕捉和拓扑门面 |

## 错误处理

| 情形 | 行为 |
|---|---|
| GDAL 无法读取或没有 CRS | 保留导入记录，禁止加入画布，并说明失败原因 |
| 无法重投影到项目基准 | 不创建参考层，提示用户修正源数据坐标定义 |
| 后台缓存或拓扑任务失败 | 保留已编辑内容与脏状态，显示可重试的问题项 |
| 参考源文件失效 | 保留图层配置，标记为离线，不影响其余图层编辑 |
| 保存时存在无效几何 | 不写入草稿，定位到首个无效要素 |

## 测试与验收

测试覆盖 GDAL 坐标统一及失败提示、参考图层草稿持久化、主/右侧/底部视图联动、矢量参考捕捉、拓扑问题定位、缓存失效和大要素场景。使用脱机 GDAL fixture，避免测试依赖外部数据源。

验收标准：

1. 任意参与编图的输入均转换至项目基准坐标，无法转换的数据不得误入画布。
2. 参考图可并排查看和叠加，单因素图与主画布可靠同步。
3. 上百个复杂要素下，平移、缩放与节点操作不因全量 Python 顶点扫描而阻塞。
4. 无效几何无法保存；普通拓扑告警可定位和追踪且默认不阻塞保存。
5. 画布优先模式不丢失编辑状态、坐标读数或快捷操作。
