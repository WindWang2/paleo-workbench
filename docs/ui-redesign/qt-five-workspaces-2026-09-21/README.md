## 设计依据

以用户提供的三张 project_area / C6 界面为准：智能预测（主图＋地震剖面＋井曲线）、约束与单因素（主图＋连井剖面）、综合编图（主图＋单因素参考图带）。早先生成的鄂尔多斯/长7数据页草案不属于本方案。

保留三阶段的科学流程和主要科学视图，增加独立数据管理与验证工作区。参考图中的重复工具、双复选框、重复阶段入口收敛；不改变计算模型或伪造已实现能力。

## 统一 Qt 外壳

- QMainWindow：菜单栏→工作区导航→上下文工具栏→可停靠内容→底部任务/日志→状态栏。
- 工作区固定顺序：数据管理、1 智能预测、2 约束与单因素、3 综合编图、验证。后两类公共工具不增加新的科学阶段。
- 工作区切换与 ProjectSession 的科学阶段分开保存。打开数据管理或验证，不改写当前科学阶段；返回原页面恢复所选对象、缩放和面板。
- 页面动作使用同一 QAction 权威；工具栏、菜单、快捷键和命令搜索调用同一命令。阶段编号只保留一处。层位标签和下拉框是同一状态的两种操作视图，禁止各自维护 C6。
- 侧边资源栏如保留图标轨，只用于资源视图/面板切换，不再出现第二套五工作区入口。
- 图层一行只保留一个可见性复选框；可编辑/锁定用独立锁图标及明确说明，不能用无标题的第二复选框。
- Agent、任务、日志作为可收起 dock，默认不挤占科学视图。显示真实就绪/运行/取消/失败状态。

## 各页面行为

### 数据管理

QTreeView按工程/实体/角色组织，QTableView使用模型与分页/惰性查询，禁止首次展开加载所有曲线或地震体。选择资产后更新预览、属性、版本和关联；多选呈现批量操作与共同属性，不冒充某个单资产。

导入使用扫描→计划→校验→确认执行的模型。原始数据只读，修改产生新版本。删除前明确引用影响；当前版本不被无提示覆盖。坏格式、缺源、未知单位、取消和过期请求分别显示，不把空白当成功。

### 智能预测

相图是核心；地震与井轨道在底部并列，用户可以单独最大化。地图选井驱动曲线选择，剖面选择定位到地图；明确当前联动组与锁定视图。运行前选输入和模型；运行时进度/取消走任务中心；完成后显式新增结果版本，不覆盖手工解释。

### 约束与单因素

保留物源线、展布线、研究区边界和等值线。选中约束后显示其属性，计算参数在右侧对应页中编辑。修改输入将相关结果标为需重算，避免将旧结果当最新。

连井顺序支持按路径选择和明确排序。图与剖面共享井身份；地层界面、砂体边界、对比线用线型和图例区分。计算、取消、保存不是同一动作。

### 综合编图

默认保持参考图中的主相图＋横向单因素参考图带。点击缩略图只切换参考对象/详情或定位，不自动替换主成果。透明度影响显示，不改变输入版本。参考图带内容虚拟化，避免重复解析同一大栅格。

编图图层/图件整饰/版式输出为同一个右dock的页签。进入版式模式才显示纸张、图框、图例和比例尺控件。导出先确认内容/格式/分辨率，报告真实写入结果。未验证成果可以按策略保存草稿，不能自动标为已发布。

### 验证（地学成果验证）

验证对象固定到明确成果版本，基准固定到明确观测/解释版本。支持地图、井/连井、地震或3D对照视图；默认打开与当前问题相关的视图，不强制同时显示所有渲染器。

空间/井点符合、层位一致、输入版本检查产生结构化问题。每条问题包含对象、范围、规则、阈值/实际值、基准、证据、运行时间、状态及复核记录。点击问题同步定位相关视图；不能只弹一段文本。

状态至少区分通过、未通过、待复核、未执行、不适用、已过期。已复核仅代表记录了人工结论，不把原检查失败自动改成通过；接受差异必须说明理由。输入版本变化时原报告保留，但标记已过期并提示重跑。保存记录与发布成果是不同命令。

岩性与沉积相必须分别验证。井深m、地震双程时ms只有在存在明确时深关系时才联动，不直接共享数值轴。CRS不一致先转换并说明，缺转换条件则禁止叠加。分类色标需对齐类别，连续变量需对齐单位与范围。

## 设计图与实现验收的边界

这些是图像生成的设计示意，不是运行截图或科学计算结果。图中少量标签/数值可能有误；例如参考图延续的重复A18井标、相带与岩性栏命名，落地时必须以真实对象ID和上述语义规则纠正。禁止将截图中的假数据或状态硬编码进产品。

实施验收：五页面切换共享工程/层位；所选井和联动视图一致；Qt布局可调整并恢复；大数据不阻塞GUI；失败/取消/过期状态真实；验证记录可重开和追溯；三阶段旧流程仍可完成。图面一致性在基本行为通过后检查，不用视觉相似替代功能验收。
