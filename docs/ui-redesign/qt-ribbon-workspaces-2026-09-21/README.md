## 层次与尺寸

Windows标题栏 → 文件菜单＋五个工作区标签 → 轻量Ribbon命令带 → 图面层位标签 → 停靠工作区 → 任务/日志 → 状态栏。

- 五个工作区标签就是 Ribbon 标签，不再复制一套页面导航。只有中间三页代表科学阶段；数据与验证不改变科学阶段。
- 原传统菜单命令收敛到文件菜单、分组菜单和命令搜索，不能因视觉整理丢失原快捷键或低频命令。
- 标准模式：命令带目标76–96逻辑像素，不含标签行；主按钮32px图标，次级动作16–20px图标＋文字、最多两行。分组名放底部。
- 紧凑模式：命令带40–48逻辑像素，小图标＋文字；空间不足时次级动作进入组内菜单。禁止不断缩小文字。
- 折叠模式：只保留标签行，点击标签临时展开；双击活动标签或折叠按钮切换固定/折叠状态。可提供Ctrl+F1并先检查现有快捷键冲突。
- 图中的比例是视觉提案，实施以逻辑像素、字体度量和不同DPI实测为准。至少检查1280×720、1672×941、1920×1080和100%/150%/200%缩放。
- 不为了Ribbon增加高度而挤掉完整连井剖面或单因素参考带。小屏优先紧凑/折叠Ribbon、可收起右dock及详情。

## 命令与上下文

每页只有一个默认主动作：导入数据、运行预测、计算单因素、导出图件、运行验证。取消仅在任务可取消时启用，运行中的主动作不能重复提交相同任务。

保存、撤销、重做是固定快捷访问区，行为随活动文档路由。Ribbon按钮、菜单、快捷键、命令搜索复用同一QAction，禁止新增平行命令实现。捕捉/联动等切换项与画布控件同步，但不维护第二份状态。

选中约束线、标注、图例或地图框时，可在当前Ribbon内显示对应上下文组；不新增一套顶层工作区，也不让组出现/消失时其它主按钮大幅跳位。无工程/无图层/只读/任务忙时禁用相关动作并提供具体原因。

层位下拉和层位标签绑定同一ProjectSession状态；鼠标焦点不应擅自改变层位。数据管理批量选择跨层位时显示全部/多个层位，不强制过滤成C6。

## 保留的工作区布局

- 智能预测：主图＋下方地震与测井两联窗，右侧图层/参数/样式。
- 约束与单因素：主图＋完整连井剖面，右侧约束/因素/参考及岩性图例。
- 综合编图：主图＋五张参考图带＋详情，版式通过工具/标签进入，不替换默认编图视图。
- 数据管理：实体树＋资产表＋数据预览，右侧属性/版本来源。
- 验证：固定对象版本与基准，地图/地震/井对照、问题定位、复核理由与报告；复核不等于检查通过。

## Qt 实施边界

复用当前AppShell、WorkstationFrame、QDockWidget和既有QAction。轻量Ribbon可由QTabBar、QStackedWidget、QToolButton、布局和分隔线组成；本设计不要求引入某个第三方Ribbon库。先检查工程现有组件，避免再造第二套主题/动作系统。

使用统一QPalette/主题token；图标同一尺寸与风格，不把生成图裁成按钮图片。焦点、键盘遍历、菜单访问和辅助文本必须可用。设置面板负责复杂参数，Ribbon只承载高频命令与关键选择。

## 验收与设计图说明

五张为同一方案的不同页面，并非待选的五种风格。它们是图像生成的概念稿，示意数据、少量文字及控件几何不是实施真源。井标必须来自唯一对象ID；岩性与沉积相分别对照；地震双程时ms与井深m必须经明确时深关系转换后才能联动。图像中的表现与这些规则冲突时以规则和真实数据为准。

实施验收：五页状态保持、动作与旧菜单等价、折叠/紧凑可用、键盘可达、不挤掉主要科学视图、任务取消与重复提交正确、DPI不裁切、布局重开恢复。界面实现前先以本设计确定信息层次，再按实际控件测量微调。
