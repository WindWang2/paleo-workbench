# D-line seismic_viewer fixtures

New D-owned verification data goes here. The frozen `tiny_sgy` oracle is
consumed READ-ONLY from `tests/cpp/science/fixtures/seismic/tiny_sgy/` (see
`PWB_SEISMIC_VIEWER_SCIENCE_FIXTURES`); it is never copied or regenerated by
this line. Current D-line tests are self-synthesizing (deterministic float
patterns), so this directory intentionally holds no binaries yet.
